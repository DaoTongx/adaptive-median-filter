## 2. 任务描述

### 2.1 要解决的问题

椒盐噪声是传感器故障、传输误码造成的典型**脉冲噪声**：
部分像素被随机置为 0（椒）或 255（盐）。它的特点是与邻域完全无关，属于孤立点。

中值滤波对脉冲噪声天然有效，但**固定窗口存在无法调和的矛盾**：

- 窗口小（3×3）：噪声密度高时窗口内脉冲占比过大，中值被污染，去噪不干净；
- 窗口大（7×7）：噪声密度低时会过度平滑，把真实边缘和细纹理一并抹掉。

一个固定参数无法同时满足"密度未知、且随位置变化"的真实场景。

### 2.2 算法原理

自适应中值滤波（简称 AMF）让**每个像素独立决定窗口大小**。
记当前窗口内的最小、最大、中值像素为 $z_{min}, z_{max}, z_{med}$，中心像素为 $z_{xy}$，
允许的最大窗口边长为 $S_{max}$，窗口从 3×3 起逐级放大。

**第 A 级：判断当前窗口的中值是否可信**

$$z_{min} < z_{med} < z_{max}$$

- 成立：中值既不是最小值也不是最大值，说明**中值不是脉冲**，窗口内的信息可用，转入第 B 级；
- 不成立：中值本身仍是极值（窗口内脉冲太多），**放大窗口**后重复第 A 级；
  若已达 $S_{max}$，则输出当前 $z_{med}$。

**第 B 级：判断中心像素是否为脉冲**

$$z_{min} < z_{xy} < z_{max}$$

- 成立：中心像素不是极值，是真实细节，**原样输出 $z_{xy}$**（这一条是保细节的关键）；
- 不成立：中心像素是脉冲，**用 $z_{med}$ 替换**。

两级判据的作用很直观：A 级决定"用什么替代"，B 级决定"要不要替代"。

### 2.3 与基线方法的差异

| | 固定窗口中值滤波（基线） | 自适应中值滤波（本作业） |
|---|---|---|
| 窗口大小 | 全图统一，调用前固定 | 逐像素从 3×3 起按需放大至 $S_{max}$ |
| 对中心像素 | 无条件用中值替换 | 若中心非脉冲则原样保留 |
| 低噪声图像 | 明显模糊 | 几乎无损 |
| 高噪声图像 | 窗口不够则去不干净 | 自动放大窗口 |
| 计算量 | 一个窗口一次中值 | 最坏 $S_{max}$ 级，每级 3 次滤波 |

### 4.2 改动前后对照

**改动 1：新增自适应窗口逻辑**（`median_adaptive.py`，核心改动）

```python
# before —— median_baseline.py：窗口固定，无条件取中值
def median_fixed(img, k=3):
    return ndimage.median_filter(img, size=k, mode="reflect")

# after —— median_adaptive.py：逐像素逐级放大窗口，两级判据决定输出
for r in range(1, r_max + 1):
    k = 2 * r + 1
    z_min = ndimage.minimum_filter(src, size=k, mode="reflect")
    z_max = ndimage.maximum_filter(src, size=k, mode="reflect")
    z_med = ndimage.median_filter(src, size=k, mode="reflect")

    pass_A  = (z_med > z_min) & (z_med < z_max)   # A 级：中值可信？
    decide  = undecided & pass_A

    center_ok = (src > z_min) & (src < z_max)     # B 级：中心是脉冲？
    out[decide & center_ok]  = src[decide & center_ok]    # 保原值
    out[decide & ~center_ok] = z_med[decide & ~center_ok] # 用中值

    undecided &= ~pass_A                          # 已定案的像素不再参与
```

**改动 2：把逐像素循环改为整图向量化**

朴素写法要对每个像素、每个窗口半径分别求 min/max/median，在 512×512 上需
`512×512×3×4 ≈ 300 万次` 小窗口运算，非常慢。本实现改为：

- 每个半径下对**整幅图**一次性求 $z_{min}, z_{max}, z_{med}$；
- 用布尔掩码 `undecided` 标记"尚未定案"的像素，逐级缩小处理范围；
- 已定案的像素自动退出后续计算，噪声密度越高反而省下部分计算。

向量化版与逐像素版（`adaptive_median_naive`）在 $S_{max}=3,5,7$ 下输出**逐像素完全一致**
（最大差值 0），说明优化没有改变算法语义。

**改动 3：修正边界填充模式不一致的问题（调试记录）**

最初 `median_fixed` 用 `scipy.ndimage` 的 `mode="reflect"`，而教学版用
`np.pad(mode="reflect")`，两者输出不一致。原因：

- `scipy.ndimage` 的 `reflect` 是**半样本对称** `d c b a | a b c d | d c b a`；
- `numpy.pad` 的 `reflect` **不重复边界** `d c b | a b c d | c b a`。

因此在 numpy 侧改用 `mode="symmetric"` 才与 scipy 对齐。修正后两种实现输出完全相同
（差值 0），这一条也保证了后续所有对比建立在同一套边界约定上。

### 4.3 基线说明

`median_baseline.py` 提供两个版本：

- `median_fixed()`：基于 `scipy.ndimage.median_filter`，作为性能与结果的工程基准；
- `median_fixed_naive()`：基于滑动窗口视图的直观实现，用于对照与教学展示。

二者在 $k=3,5,7$ 下输出完全一致。

> 说明：自适应中值滤波是 Gonzalez & Woods《数字图像处理》中的经典算法，本作业的工作是
> **复现该算法、给出高效向量化实现、并设计系统性评测**，而非提出新算法。

### 5.1 实验设置

- 测试图：4 张（camera / coins / moon / text），512×512 灰度；
- 噪声密度：0%、5%、10%、20%、30%、40%、50%；
- 对比方法：固定 3×3 / 5×5 / 7×7，以及 AMF 取 $S_{max}=5/7/9$；
- 指标：PSNR（dB）、SSIM，均在 8 位动态范围下计算；耗时取 3 次中位数（含 1 次预热）。

### 5.4 关键发现

**（1）AMF 同时赢在两端，而固定窗口必须二选一**

- **0% 噪声（保细节）**：AMF(S=7) 为 **40.77 dB**，高于固定 3×3 的 37.69 dB（+3.08 dB）、
  远高于固定 7×7 的 32.08 dB（+8.69 dB）。原因是 B 级判据让非脉冲像素原样输出，
  整幅图几乎无损。
- **50% 噪声（强去噪）**：AMF(S=7) 为 **32.76 dB / SSIM 0.9226**，
  超过最好的固定窗口（7×7，29.63 dB / 0.8294），**+3.13 dB / +0.093 SSIM**；
  而固定 3×3 在此密度下彻底失效（15.34 dB / SSIM 0.2116）。

固定窗口中，3×3 保细节强但高密度失效，7×7 高密度勉强可用但低密度严重模糊。
AMF 用自适应窗口把这条"取舍曲线"整体抬高了。

**（2）$S_{max}$ 的收益递减**

$S_{max}$ 从 5 增到 7，50% 密度下 PSNR 提升 **+5.46 dB**（27.30→32.76）；
从 7 增到 9 只再提升 **+0.20 dB**（32.76→32.96），但耗时从 241 ms 增至 428 ms（**+77%**）。
因此 **$S_{max}=7$ 是性价比最优点**。

**（3）代价：计算时间增加约 2.1 倍**

| 方法 | 平均耗时 (ms) | 相对固定 3×3 |
|---|---|---|
| 固定 3×3 | 18.4 | 1.0× |
| 固定 5×5 | 63.8 | 3.5× |
| 固定 7×7 | 114.6 | 6.2× |
| AMF(S=5) | 115.8 | 6.3× |
| AMF(S=7) | 241.0 | 13.1× |
| AMF(S=9) | 427.7 | 23.2× |

AMF(S=7) 相对固定 7×7 约为 **2.1 倍**耗时，换来 3 dB 以上的质量提升，在这一场景下是划算的。

### 5.6 局限

1. **只适用于脉冲噪声**。对高斯噪声无效。因为 A 级判据假设"噪声是极值"，
   高斯噪声下 $z_{med}$ 与 $z_{xy}$ 都落在 $[z_{min}, z_{max}]$ 内，两级判据会直接放行，
   等效于不做处理。
2. **计算量较大**。最坏情况需 $S_{max}$ 级、每级 3 次全图滤波，比固定窗口慢一个量级。
3. **平坦区效率低**。全同灰度区域 $z_{min}=z_{max}$，A 级永真值不成立，会一路放大到 $S_{max}$
   才输出，做了大量无用功。
4. 本作业未与更先进的去噪方法（如 BM3D、深度学习去噪）对比，比较范围限定在
   中值滤波家族内部。
